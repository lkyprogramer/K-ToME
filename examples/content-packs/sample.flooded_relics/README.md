# Sample Flooded Relics Content Pack

This official sample pack is an ADD-first authoring example for Phase 4 content-pack visibility.

- Main runtime overlays use only `ADD`.
- `REPLACE`, precedence, and conflict examples live in `tools/src/main/resources/fixtures/content-packs/packs/fixture_sample_flooded_relics_override/`.
- New content ids must use the `sample.flooded_relics.` namespace.
- Visual, audio, and i18n keys use the `sample_flooded_relics.*` prefix.
- The pack does not change core rules, damage types, resource types, or base registry items.
