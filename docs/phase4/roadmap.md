# Phase 4 Roadmap（入口）

## 1. Phase 4 主题

Phase 4 的主题是把“可完成的长局”升级成“重复游玩差异明显的长局”，同时把内容扩展点做成正式数据包路径。

目标主线：

`长局成立 -> ProcGen 深化 -> Loot 生态深化 -> Content Pack Overlay`
