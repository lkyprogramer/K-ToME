# Phase 5 Roadmap（入口）

## 1. Phase 5 主题

Phase 5 的主题是把已经稳定的规则和内容提升到发布级：战术 AI、感知/潜行、性能、回放、QA 和安装包全部收口。

目标主线：

`系统稳定 -> 战术 AI -> perf/soak/replay -> QA 清盘 -> v1.0.0`
