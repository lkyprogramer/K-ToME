# Phase 4 深度审查报告 — Part 2：当前阶段玩法体验总评

---

## 4. 当前阶段玩法体验总评

### 4.1 核心循环（Core Loop）审查

**当前循环结构：**

```
创角(职业+种族选择) → 进入 Zone → 回合制探索地图
  → 遇敌战斗 → 获取经验+掉落 → 升级/装备/天赋决策
  → 发现隐藏内容(可选) → 击败 Boss(如有) → 前往下一 Zone
  → ... → 最终区域 → 通关/死亡 → 重开
```

**判断：循环骨架成立，但驱动力在中段严重衰减。**

#### 4.1.1 循环各环节评估

| 环节 | 评分 | 说明 |
|------|------|------|
| 创角选择 | ★★★★☆ | 4 基础 + 2 可用进阶职业，资源轴差异化（STAMINA/MANA/ENERGY/POSITIVE_ENERGY/HATE/EQUILIBRIUM），初始 build 差异显著 |
| 地图探索 | ★★★☆☆ | 拓扑差异机制正确，但单个 zone 内的房间填充缺乏叙事性标记——玩家走的是"有差异的随机走廊"，不是"有故事的不同地点" |
| 战斗遭遇 | ★★★☆☆ | 战斗公式健全、6 通道伤害 + Power/Save 对抗 + 状态效果，但精英突变仅 6 种且分布不均，导致"战斗感觉都差不多" |
| 掉落获取 | ★★☆☆☆ | 预算公式正确但终端感知弱。每个 zone 的 loot profile 只有 4~6 个固定 base item，affix 仅 ~40 个。掉落快速进入"换了词缀的同一批东西" |
| 成长决策 | ★★★★☆ | 天赋树结构好（每职业 3 树 × 5~6 节点），属性分配有意义（str/dex/con/wil 与职业关联清晰），升级有真实感 |
| 隐藏发现 | ★★☆☆☆ | 全部 4 个 secret zone 使用同一发现机制（感知检定），无惊喜变化。"搜索"从战术选择退化为"到了 optional.branch.1 就按搜索" |
| Boss 战 | ★★☆☆☆ | 仅 3 个 Boss 变体，变体能力只是精英突变的组合。Boss 战缺乏专属机制阶段或特殊战术要求 |
| 重开动力 | ★★☆☆☆ | 职业差异提供了一定重开理由，但掉落/遭遇/隐藏内容的同质化使得"不同 seed 的体验差异"远低于"不同职业的体验差异" |

#### 4.1.2 核心循环的关键断裂点

**问题 1：掉落不构成决策驱动力**

当前掉落体验的核心问题不是"掉得少"，而是"掉的东西不影响我怎么玩"。

- 每个 zone 的 loot profile 是固定 itemIds 列表，不是"从该 zone 的特色池中随机生成"
- affix 总量约 40 个（22 prefix + 18 suffix），组合空间有限
- UNIQUE 和 ARTIFACT 严格绑定 zone + sourceTier，发现它们更像是"走到特定位置的确认"而非"意外的惊喜"
- 缺少影响 build 方向的关键装备决策（如 ToME 中"发现一把强力法杖可能让战士考虑转混合 build"的体验）

**证据**：
- `data/loot/index.yaml`：`loot.greenwood_fringe.cadence` 的 itemIds 是 `[hunter_bow, emerald_charm, leather_armor, apprentice_robe]` —— 固定 4 件
- `data/loot/index.yaml`：`loot.greenwood_hidden_cache.secret` 的 itemIds 也只有 4 件 `[hunter_bow, bandit_trophy, emerald_charm, stamina_draught]`
- 两个不同来源（cadence vs secret）的掉落池高度重叠（hunter_bow 和 emerald_charm 同时出现在两个池中）

**问题 2："前 10 分钟有趣，30 分钟后失去动力"**

Phase 4 的差异化机制集中在"宏观拓扑"层面（不同 seed 生成不同路径结构），但"微观遭遇"层面严重同质化：

- 精英突变只有 6 种，其中 4 种是 MAJOR tier，意味着大部分精英的能力只从 4 个选项中抽取
- 隐藏事件全部是"感知检定 → 揭示 → 互动 → 掉落"，无分支、无风险选择、无后续影响
- 地形交互因覆盖率太低（~8%）在实际游玩中几乎透明

这导致：第一个 zone 的体验可以是新鲜的（新地图、新 biome），但到第二个同类型 zone 时，玩家已经穷尽了所有变量组合。

### 4.2 战斗体验审查

#### 4.2.1 战斗决策有意义吗？

**结论：基础战斗决策有意义，但缺乏"因地制宜"的战术层。**

**已做好的部分：**
- 6 通道伤害 + 抗性系统提供了"用什么打什么"的基础决策
- Power/Save 三维对抗（PHYSICAL/SPELL/MENTAL）让状态命中不是自动的
- 资源管理（STAMINA/MANA/ENERGY 等）要求技能使用有节奏
- 天赋冷却 + 能量系统（1000 能量制）让回合内选择有成本

**不足的部分：**

1. **地形从未成为战术要素**
   - 5 种地形交互已编码，但触发条件极苛刻：需要敌人站在特定地形 + 玩家使用对应元素技能
   - 地形覆盖率约 8%，且分布在房间边缘而非关键战斗位置
   - 玩家没有"把敌人推到水上再放雷电"的主动战术选项
   - **根因**：地形是"被动装饰"而非"战术资源"

2. **精英突变没有改变战斗方式**
   - `STAT_PACKAGE`（stonehide）只是数值增强，打法不变
   - `ABILITY_GRANT`（battle_drill → linebreaker）增加了一个技能但不改变核心应对策略
   - `AURA`（dread_aura）是被动光环，玩家的反应只是"靠近它会弱化，所以保持距离"——但回合制走格子游戏中这一决策极为简单
   - `AI_SHIFT`（hunt_protocol）改变了敌人 AI 但玩家感知不明显
   - `ELEMENT_PACKAGE`（emberblood/tidebound）增加抗性 + 技能，是最有感知的突变类型，但只有 2 个

3. **Boss 战缺乏阶段性战术变化**
   - Boss 变体只覆盖了 actionWeightProfile（调整技能权重），没有引入阶段切换、特殊机制、战场变化
   - 对比 ToME 的 Boss 战：阶段切换、召唤小怪、场地效果、逃跑重置等——当前 Boss 战只是"更强的精英"

#### 4.2.2 职业/流派差异

**结论：基础差异显著，但装备系统未能放大差异。**

| 维度 | 评估 |
|------|------|
| 资源轴差异 | ★★★★★ 每个职业有独特资源循环：vanguard(STAMINA), arcanist(MANA), rogue(ENERGY + ON_HIT), templar(POSITIVE_ENERGY + ON_DAMAGE_TAKEN), berserker(HATE + ON_KILL), spellblade(MANA + EQUILIBRIUM) |
| 技能差异 | ★★★★☆ 每职业 3 天赋树 × 5~6 节点，开局 4 技能不同，成长路线分化清晰 |
| 装备差异 | ★★☆☆☆ UNIQUE 虽然按 zone + tag 过滤了职业关联，但 affix 是通用池，不存在"只有法师才想要的词缀组合"的构筑拉力 |
| 战术差异 | ★★★☆☆ 近战 vs 远程 vs 控制 vs 治疗的基础差异存在，但精英/Boss 没有强迫不同职业采取不同策略 |
| 构筑空间 | ★★☆☆☆ 当前没有"这件装备改变了我的 build 方向"的体验。装备是单纯的数值增强，不是构筑选择 |

#### 4.2.3 战斗节奏

**问题：普通怪战斗可能过于频繁且低价值。**

- 60 种怪物 / ~11 个 zone = 每 zone 约 5~6 种怪
- 但怪物间的行为差异主要来自 AI 配置（`data/ai/index.yaml`），大部分杂兵的战斗决策是"靠近→攻击"
- 精英只有 6 种突变，且 `minFloor` 限制了前期 zone 可用的突变种类更少
- 结果：大量"填充战斗"缺乏战术价值，拉长了游戏节奏但不增加乐趣

### 4.3 角色成长与构筑驱动审查

#### 4.3.1 成长感是否真实？

**结论：等级 + 天赋成长感真实且有效，装备成长感弱。**

| 成长线 | 感受 | 说明 |
|--------|------|------|
| 等级成长 | ✅ 真实 | `statGrowth` 每级给 str/dex/con/wil 增量，且不同职业增长方向不同（vanguard: str3/con3 vs arcanist: wil4） |
| 天赋成长 | ✅ 有效 | 天赋树有前置依赖，升级解锁新技能能改变战斗方式（如 vanguard 从 power_strike 成长到 earthshaker） |
| 装备成长 | ⚠️ 弱 | 材质系统（IRON→STEEL→MITHRIL→ADAMANTITE）提供基础数值递增，但 affix 组合变化有限，缺少改变玩法的关键装备 |
| 资源成长 | ✅ 独特 | 每个职业的资源循环在中后期有不同的节奏压力（berserker 的 HATE 需要持续战斗维持、templar 的 POSITIVE_ENERGY 靠挨打充能） |

#### 4.3.2 构筑分化是否足够？

**结论：职业内分化基础好，但跨 run 分化不足。**

**已有的分化：**
- vanguard: 武器路线(arms) / 盾牌路线(shield) / 战吼路线(warcry)
- arcanist: 火焰 / 冰霜 / 奥术
- rogue: 暗杀 / 潜行 / 敏捷
- templar: 制裁 / 恩典 / 信仰
- berserker: 狂怒 / 毁灭 / 血战
- spellblade: 附魔刃 / 元素流转 / 战斗法术

每个职业有 3 条可选路线，每条路线 5~6 个天赋，这是好的基础。

**不足的分化：**
- **装备不驱动构筑选择**：当前 affix 全部是"数值增强型"（+attack, +defense, +resistance, +regen），没有"机制改变型"词缀（如 ToME 中 "+30% 火焰伤害" 驱动法师走纯火路线、"攻击时 10% 几率释放冰锥" 驱动战士走法战混合路线）
- **UNIQUE/ARTIFACT 的 fixedAffixIds 仅是普通 affix 组合**：例如 `unique.greenwood_watcher_blade` 的 fixedAffixIds 是 `[sanctified, of_precision]`，这只是一把带固定词缀的武器，没有独特效果
- **没有互斥选择或 trade-off**：玩家不需要在"进攻还是防御"、"这条 tree 还是那条 tree"之间做痛苦选择，因为资源充足时可以全点

#### 4.3.3 "这局想试另一种 build"的驱动力

**评估：主要来自职业差异，而非装备/遭遇差异。**

- ✅ 试过 vanguard 后想试 arcanist → **强驱动**（完全不同的资源系统和战斗节奏）
- ⚠️ 同一职业换一种天赋路线 → **中等驱动**（树间差异明确但最终数值体验差异有限）
- ❌ 同一 build 不同 seed → **弱驱动**（地图拓扑不同但遭遇/掉落体验高度相似）

### 4.4 奖励驱动与掉落体验审查

#### 4.4.1 奖励是否足够频繁且有层次？

**结论：频率可能足够，但层次严重不足。**

| 奖励来源 | 频率 | 层次感 | 问题 |
|---------|------|--------|------|
| 杂兵掉落 | 高频 | ★☆☆☆☆ | loot.foundation.common 只有 6 件固定物品，重复率极高 |
| 精英掉落 | 中频 | ★★☆☆☆ | loot.foundation.elite 有 8 件，稍好但仍是固定列表 |
| Boss 掉落 | 低频 | ★★★☆☆ | 10 件且可能触发 UNIQUE/ARTIFACT，但仅限特定 zone |
| 宝箱 | 中频 | ★★☆☆☆ | CHEST sourceTier 只增加 iLvl+1 和 rarityBonus+0.10，感知弱 |
| Secret Zone | 极低频 | ★★☆☆☆ | 奖励 loot profile 与普通 cadence 高度重叠（相同 base item + 略高 rewardBudget） |
| Hidden Event buff | 极低频 | ★★★☆☆ | deep_iron 的 GUARD_STANCE_BUFF 是当前唯一有"战术价值"的事件奖励 |

#### 4.4.2 奖励是否影响下一步决策？

**结论：几乎不影响。**

当前掉落的 base item 是通用装备（short_sword, chain_mail, healing_potion 等），affix 是通用数值增强。玩家收到掉落后的决策路径是：

1. 新装备数值 > 旧装备？→ 换
2. 否？→ 丢弃

没有"这把武器有火焰词缀，我应该调整技能搭配"的深层决策。没有"这件防具降低速度但大幅加防御，值不值得"的 trade-off。

#### 4.4.3 掉落的"记忆点"

**结论：当前没有记忆点。**

ToME 的掉落记忆点来自：
- 特殊效果（"攻击时有几率传送目标"、"被击时反射 50% 伤害"）
- 稀有度视觉差异（橙色字 = 兴奋）
- 场景绑定的惊喜（"这个 Boss 居然掉了神器"）

当前 K-ToME 的 UNIQUE/ARTIFACT：
- 没有特殊效果（只是固定 affix 组合）
- 视觉差异依赖 client 实现（有 visualKey 但缺乏确认实际渲染差异）
- 掉落场景可预测（严格绑定 zone + sourceTier）

### 4.5 探索与新鲜感审查

#### 4.5.1 地图差异是否支撑重复游玩？

**结论：宏观差异有，微观差异不足。**

| 差异维度 | 状态 | 说明 |
|---------|------|------|
| 拓扑结构 | ✅ 有效 | 不同 seed 生成不同的 room→corridor→loop→vault 结构 |
| Biome 着色 | ✅ 有效 | 每 zone 2 个 biome 混合，地形标签分布不同 |
| 房间内容 | ⚠️ 弱 | 房间是"有标签的几何空间"，缺乏叙事元素、环境叙事、可互动对象 |
| Vault 惊喜 | ⚠️ 有限 | 每 zone 只有 2 个 vault 可选，多次游玩后会遇到相同 vault |
| Pattern Room | ⚠️ 有限 | 8 个 pattern 模板在 4 个 zone 中分布使用，重复率较高 |

#### 4.5.2 内容重复度

**问题：4 个升级 Zone × 2 vault/zone = 8 vault 总量，搭配 8 pattern × 8 biome，在约 5 次 run 后主要组合将被穷尽。**

文档承诺"地图差异≥3类可感知差异"：
1. 拓扑形态 ✅
2. 库位出现 ✅
3. 生物群系混合 ✅

但这三类差异都在"结构层"，缺少"内容层"差异（不同的文字描述、不同的环境事件、不同的 NPC 对话、不同的谜题/陷阱）。

#### 4.5.3 "再来一局"的理由

在当前 Phase 4 下，玩家再开一局的理由排序：

1. **换一个职业** → 最强理由（6 个可用职业提供了 6 次本质不同的游戏体验）
2. **换一条天赋路线** → 中等理由（每职业 3 树，约提供 2~3 次有差异的重玩）
3. **看到不同地图** → 弱理由（拓扑差异存在但内容填充相似）
4. **获得不同装备** → 极弱理由（掉落池太小，affix 变化有限）
5. **发现隐藏内容** → 极弱理由（4 个 secret zone 机制完全相同，一旦见过就无惊喜）

**总估算**：当前版本能支撑约 6~10 次有意义的重玩（主要由职业差异驱动），之后体验将高度重复。对于 Roguelike 来说，这个数字偏低。ToME 同类阶段应至少支撑 20~30 次。

### 4.6 新手体验与信息反馈审查

#### 4.6.1 目标清晰度

**评估：中等。**

- ✅ 每个 zone 有 `objectiveSetId`（如 `greenwood_signal_hunt`），目标系统存在
- ✅ 世界图 `data/world/world_graph.yaml` 定义了 zone 间拓扑
- ⚠️ 但缺乏"当前最优行动提示"——新手可能不知道该先去哪个 zone、何时使用 SearchAction、为什么要走支线

#### 4.6.2 数值反馈

**评估：框架完善，但感知层未验证。**

- ✅ CombatResolutionTrace 记录完整战斗计算过程
- ✅ 事件系统输出 LogToken 而非文案（正确的 i18n 架构）
- ⚠️ 但 Phase 4 的 client 可读性要求只覆盖了 hidden content 相关的 UI，未覆盖掉落/affix/rarity 的视觉反馈
- ⚠️ 玩家看到一件 RARE 物品时，是否能快速理解它比 MAGIC 好在哪里？当前未见明确的 rarity 视觉分层设计

#### 4.6.3 死亡可理解性

**评估：依赖 Phase 3 已有的 CombatTrace 系统。**

- ✅ 死因可追踪（CombatResolutionTrace 记录了每步伤害源、抗性计算、状态效果）
- ⚠️ 但信息是否以玩家可理解的方式呈现？这取决于 client 层的 UI 设计，Phase 4 未对此做增量

### 4.7 系统联动性审查

#### 4.7.1 各系统是否互相支持？

| 系统对 | 联动状态 | 说明 |
|-------|---------|------|
| 地图生成 ↔ 战斗 | ⚠️ 弱联动 | 地形标签已接入 CombatPipeline Step 9，但覆盖率太低，实战中联动不可感知 |
| 地图生成 ↔ 掉落 | ✅ 中等联动 | ZoneRewardProfile 影响 rarityBonus/qualityBonus，zone 间确实有掉落品质递增 |
| 精英突变 ↔ 掉落 | ✅ 有联动 | Elite sourceTier 提供 iLvl+1 / rarityBonus+0.15 / affixBudgetBonus+2 |
| 隐藏内容 ↔ 掉落 | ⚠️ 弱联动 | Secret zone 有独立 loot profile 但内容与普通掉落高度重叠 |
| 天赋成长 ↔ 战斗 | ✅ 强联动 | 天赋直接影响技能可用性和战斗策略 |
| 装备 ↔ 构筑 | ❌ 无联动 | 装备只提供数值增强，不改变构筑方向 |
| 地形 ↔ 精英突变 | ❌ 无联动 | 精英的突变不考虑所在房间的地形，tidebound 精英不一定站在水面上 |
| Content Pack ↔ 游戏体验 | ✅ 架构正确 | sample.flooded_relics 验证了 pack 内容可以无缝融入，架构联动正确 |

#### 4.7.2 体验断层识别

**断层 1：探索层与战斗层脱节**

地图生成系统产生了丰富的拓扑结构（环路、分支、vault），但这些结构对战斗没有影响。走一条环路和走一条直线，遇到的战斗体验相同。地图差异是"路径差异"，不是"体验差异"。

**断层 2：掉落层与成长层脱节**

掉落系统有精确的数学模型（iLvl/qLvl/rarity budget），但掉落的物品不驱动角色成长方向的变化。装备替换是"数值更高就换"，不是"这件装备让我考虑换一种打法"。

**断层 3：隐藏内容层与核心循环脱节**

Secret zone 的奖励是独立 loot profile 中的固定物品，不影响核心循环的任何决策。发现一个 secret zone 的体验是"多拿了几件普通装备"，不是"获得了改变局势的关键物品"。

**断层 4：地形交互层完全浮空**

5 种地形交互已编码但在实际游戏中几乎不触发。这是一个"技术上完成了但体验上不存在"的系统。它既不增加战术深度，也不增加探索乐趣，当前状态下是纯粹的开发成本。
