## 1. 风格标签

固定风格标签：

`ktome-middle-fantasy-painterly-tile-v1`

这不是运行时资源 key，而是所有离线图像生成、人工评审、批量处理和 prompt 模板的统一风格锚点。

---

## 2. 阶段边界

本文是 `Phase 2+` 的正式资源风格约束，不是对 `Phase 1` 已完成 ASCII 基线的追溯性要求。

冻结规则：

1. `Phase 1` 的 ASCII 和占位图不要求回头对齐本文。
2. 从 `Phase 2` 开始新增的正式图片资产，必须对齐本文。
3. `Phase 2` 允许先做最小 Tile 集，但即使是最小集也必须服从本文。
4. `Phase 3 ~ Phase 5` 的资源扩容只能在本文基础上深化，不允许重新换主风格。

## 3. 风格总方向

### 2.1 世界气质

K-ToME 的美术必须表现为：

1. 古典高幻想
2. 中古时代材料感
3. 神秘但克制的魔法感
4. 长年战争与荒废之后的历史磨损感
5. 沉稳、史诗、危险、寒冷与火光交织的世界

可以用一句话概括：

`像一片被岁月、铁器、苔藓、火焰和旧誓言浸透的中土式高幻想世界。`

## 4. 核心视觉原则

### 3.1 可读性优先于细节

所有正式资产必须优先服务玩法读图。

具体要求：

1. 小尺寸运行时首先看轮廓，不首先看细节。
2. 危险目标、可交互物、Boss telegraph、地表危害必须一眼能分层。
3. 玩家、怪物、机关、地形的视觉语言必须可区分。
4. 不允许为了“概念图好看”牺牲 48x48 或 64x64 下的辨识度。

### 3.2 写实偏绘景，不走照片或像素风

渲染质感固定为：

1. painterly
2. concept-art finish
3. 轻微笔触感
4. 材料分明
5. 阴影克制

禁止：

1. 纯照片拼贴感
2. 极端写实皮肤毛孔细节
3. 像素风
4. Q 版或 chibi 化

### 3.3 正交 Tile 友好

本项目正式地图是正交网格，不是等角。

因此所有环境资产必须满足：

1. 顶面、正面、轮廓清晰
2. 占格关系明确
3. 不依赖透视夸张
4. 不做会误导碰撞边界的“概念图式漂浮结构”

## 6. 形体语言

### 5.1 角色轮廓

角色必须有强 silhouette。

建议方向：

1. Vanguard：盾、肩甲、披风、前压重心
2. Arcanist：长袍、法杖、层叠织物、法术焦点
3. Rogue：窄肩线、斗篷、短刃、低姿态
4. Templar：圣徽感护甲、长柄兵或重剑、圣布与铁甲混合
5. Berserker：宽肩、双手武器、裸露或破损甲片、野蛮前倾
6. Spellblade：半甲半袍、元素符纹武器
7. Shadowblade：暗色披风、弯刃、碎片化阴影轮廓
8. Warden：游侠式肩背装备、双武器或弓刃混合

### 5.2 怪物轮廓

怪物必须按战斗职责就能看出区别：

1. `BRUTE`：宽、重、低速、压迫感强
2. `DUELIST`：细长、灵巧、偏人形
3. `SKIRMISHER`：轻、快、侧身姿态明显
4. `ARTILLERY`：法杖、投射器、远端焦点
5. `CONTROLLER`：触须、法器、图腾、异质结构
6. `SUMMONER`：祭司、召唤焦点、仪式感

1. 风化石材

3. 旧木
4. 皮革
5. 羊毛/粗布
6. 骨、角、枯枝

3. 玻璃霓虹

5. 过于干净的白瓷或银白表面

## 9. 光照原则

### 8.1 全局光照

固定倾向：

1. 低调照明
2. 侧上方主光
3. 暖火光和冷环境光并存
4. 阴影清晰但不过黑

### 8.2 交互资产的局部高光

允许但必须克制：

1. 角色肩线和武器边缘的 rim light
2. 可交互机关的轻微边缘亮部
3. 法术核心和符文槽位的局部发光

禁止：

1. Bloom-heavy haze
2. 满屏体积光
3. 纯梦幻仙气

## 12. UI 与图标风格

### 11.1 UI 框架

UI 不是现代扁平化面板，而应表现为：

1. 旧铁框
2. 石板
3. 皮革边
4. 羊皮纸
5. 铆钉和磨损边角

### 11.2 图标

图标必须：

1. 单主体
2. 高对比
3. 方向明确
4. 不塞多元素叙事
5. 保持同一笔触和边缘逻辑

### 11.3 禁止的 UI 感觉

1. 科幻发光按钮
2. 玻璃拟态
3. 廉价手游宝箱金光
4. 过于现代的简约办公软件图标

## 13. 资产家族规范

### 12.1 Tile

要求：

1. 64x64 authoring
2. 48x48 默认运行时
3. 顶面与边界清晰
4. 留出碰撞和遮挡识别空间

### 12.2 Prop

要求：

1. 明确 footprint
2. 轮廓先于细节
3. 大型 prop 要有上部和基底的清晰分离

### 12.3 Portrait

要求：

1. 3/4 角度优先
2. 脸部表情克制
3. 不做影视明星脸
4. 强调身份与职业而不是“颜值”

### 12.4 Icon

要求：

1. 背景纯净
2. 轮廓锐利
3. 中心主体大
4. 小尺寸仍可识别

### 12.5 VFX Source Plate

要求：

1. 允许更抽象
2. 但仍遵守元素和世界观语言
3. 不做高饱和噪点烟花

## 14. Prompt 生成规则

### 13.1 Prompt 组成

每个图像 prompt 固定由以下部分组成：

1. `Asset identity`
2. `World role`
3. `Material cues`
4. `Lighting cues`
5. `Camera/readability cues`
6. `Style tag`
7. `Hard constraints`

### 13.2 Prompt 模板骨架

```text
{asset_type}, {subject}, in a weathered middle-fantasy world of worn stone, forged iron, old timber, moss, mist and ember light, painterly concept-art finish, readable silhouette at gameplay scale, restrained color saturation, clear orthographic-friendly form, no text baked into image, no logo, no watermark, original IP only, style tag: ktome-middle-fantasy-painterly-tile-v1
```

### 13.3 统一负面约束

所有 prompt 默认追加：

```text
Avoid: neon, sci-fi materials, anime face, chibi proportions, oversaturated magic glow, modern symbols, franchise emblems, watermark, logo, text, UI baked into image.
```

## 15. 硬性红线

### 14.1 版权红线

禁止：

1. 直接使用《指环王》《魔戒》具体角色脸
2. 直接使用具体电影构图
3. 使用可识别的电影/游戏徽章、家纹、专名
4. 直接复刻受保护武器和盔甲设计

允许：

1. 借用“中土式历史感、气候、材料和史诗气质”
2. 借用“旧世界、高幻想、衰败文明、火与雾”的氛围

### 14.2 可读性红线

禁止：

1. 背景比主体更复杂
2. Tile 资产边缘模糊到看不出碰撞
3. 同类危险对象没有统一危险色语言
4. 重要交互物与普通装饰物视觉地位一致

### 14.3 技术红线

禁止：

1. 图片中烘焙技能名、描述、数值
2. 直接把生成大图不处理就塞进运行时
3. 不保留 raw 输出和处理记录

## 16. 评审清单

每张正式资产评审时必须回答：

1. 它属于哪个 biome / faction / profession / encounter？
2. 它在 48x48 下轮廓是否仍清晰？
3. 它是否符合本文的材质、调色和光照纪律？
4. 它是否误触了现成影视 IP 视觉记忆点？
5. 它是否已经避免烘焙文字与 UI？
6. 它是否和同类资产在世界观上属于一个家族？
7. 它是否能映射到明确的 `visualKey`？

## 18. 后续使用规则

1. 所有新图像生成必须显式引用本文风格标签。
2. 所有 `AssetSpec` 必须声明所属风格族群。
3. 若生成结果与本文冲突，以本文为准，不以“模型发挥”为准。
4. 本文如果后续更新，必须 bump 风格版本，例如：
   - `ktome-middle-fantasy-painterly-tile-v2`

---

## 19. 一句话原则

K-ToME 的画面不是“更华丽的随机奇幻图”，而是：

`一个能在小尺寸 Tile 上依然读得清、带有中土式历史感和危险感的古典高幻想世界。`
