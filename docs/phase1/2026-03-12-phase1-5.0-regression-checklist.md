# Phase 1 1-5.0 Regression Checklist

## 1. Automated Verification

Run the release-stage checks from the repository root:

```bash
./gradlew preReleaseAcceptance
```

This task is the release-stage umbrella gate. It expands to:

```bash
./gradlew clean test
./gradlew headlessSmoke
./gradlew clientSmoke
./gradlew jacocoTestReport
./gradlew :core:jacocoTestCoverageVerification
./gradlew :client:releaseDesktopDist
```

Expected outcomes:

1. `preReleaseAcceptance` succeeds without manual task reordering.
2. `test` succeeds for `core`, `game`, and `client`.
3. `headlessSmoke` writes AI harness reports under:
   - `build/reports/harness/headless-smoke.json`
   - `build/reports/harness/headless-smoke.md`
4. `clientSmoke` writes lifecycle smoke reports under:
   - `build/reports/harness/client-smoke.json`
   - `build/reports/harness/client-smoke.md`
5. `jacocoTestReport` writes aggregate and module coverage reports under:
   - `build/reports/jacoco/jacocoTestReport/html/index.html`
   - `core/build/reports/jacoco/test/html/index.html`
   - `game/build/reports/jacoco/test/html/index.html`
   - `client/build/reports/jacoco/test/html/index.html`
6. `:core:jacocoTestCoverageVerification` succeeds with:
   - `core` total line coverage `>= 80%`
   - `combat / map / talent / item / save / dungeon / run` package line coverage `>= 85%`
7. `:client:releaseDesktopDist` produces `client/build/release/ktome-v0.1.0-desktop.zip`.

Nightly-only long run validation remains separate:

```bash
./gradlew longRunLab
```

Expected nightly evidence:

1. `build/reports/harness/long-run-summary.json`
2. `build/reports/harness/long-run-summary.md`

## 4. Manual White-Box Steps

Launch the client:

```bash
./gradlew :client:run
```

Checklist:

1. Start a new game from the main menu.
2. Use `x` to inspect the player, at least one monster, and at least one ground item.
3. Reach a stair tile and verify `>` / `<` floor transitions still work.
4. Save with `Ctrl+S`, return to the menu, continue, and confirm the floor plus inventory are restored.
5. Complete one victory path and one death path.
6. Unzip `client/build/release/ktome-v0.1.0-desktop.zip`, run the packaged launcher once, and confirm it starts without Gradle.
7. Compare the desktop experience against `build/reports/harness/headless-smoke.json` and `client-smoke.json`; record any divergence instead of silently accepting it.

## 6. Release Sign-off Notes

Before declaring `v0.1.0` releasable, explicitly record:

1. Which automated commands were actually executed.
2. Whether `./gradlew :client:run` was actually exercised on a desktop environment.
3. Whether the packaged archive was actually launched outside Gradle.
4. Which limitations remain accepted, and that they match `docs/releases/v0.1.0-known-limitations.md`.
