# Phase 1 1-5.0 Regression Checklist

## 1. Automated Verification

Run the release-stage checks from the repository root:

```bash
./gradlew clean test
./gradlew jacocoTestReport
./gradlew :core:jacocoTestCoverageVerification
./gradlew :client:releaseDesktopDist
```

Expected outcomes:

1. `test` succeeds for `core`, `game`, and `client`.
2. `jacocoTestReport` writes aggregate and module coverage reports under:
   - `build/reports/jacoco/test/html/index.html`
   - `core/build/reports/jacoco/test/html/index.html`
   - `game/build/reports/jacoco/test/html/index.html`
   - `client/build/reports/jacoco/test/html/index.html`
3. `:core:jacocoTestCoverageVerification` succeeds with:
   - `core` total line coverage `>= 80%`
   - `combat / map / talent / item / save / dungeon / run` package line coverage `>= 85%`
4. `:client:releaseDesktopDist` produces `client/build/release/ktome-v0.1.0-desktop.zip`.

## 2. Fixed-Seed Manual Runs

Use the following seed set for regression sampling:

| Seed | Target | Record |
| --- | --- | --- |
| `20260312` | baseline full clear pace | outcome / floor / turns / notes |

| `20260315` | loot pacing | item spikes / dead floors / notes |
| `20260316` | boss approach | floor 5 readiness / boss outcome / notes |

## 3. Manual White-Box Steps

Launch the client:

```bash
./gradlew :client:run
```

Checklist:

1. Start a new game from the main menu.
2. Use `x` to inspect the player, at least one monster, and at least one ground item.
3. Reach a stair tile and verify `>` / `<` floor transitions still work.
4. Save with `Ctrl+S`, return to the menu, continue, and confirm the floor plus inventory are restored.
5. Complete one victory path and one death path.
6. Unzip `client/build/release/ktome-v0.1.0-desktop.zip`, run the packaged launcher once, and confirm it starts without Gradle.
