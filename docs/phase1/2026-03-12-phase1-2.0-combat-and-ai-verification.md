# Phase 1 1-2.0 Verification Checklist

## 1. Automated Verification

If Gradle cannot resolve remote artifacts because of TLS or proxy issues, bootstrap the local repository first:

```bash
./scripts/bootstrap-deps.sh
```

If the change touches dependency versions, build scripts, Gradle wrapper metadata, or bootstrap logic, run the offline smoke check as well:

```bash
./scripts/verify-bootstrap.sh --clean
```

Run the following commands from the project root:

```bash
./gradlew test
./gradlew :core:test --tests "com.ktome.core.turn.*"
./gradlew :core:test --tests "com.ktome.core.combat.*"
./gradlew :game:test
./gradlew jacocoTestReport
./gradlew :core:jacocoTestCoverageVerification
```

Expected outcomes:

1. `test` succeeds.
2. `:core:test --tests "com.ktome.core.turn.*"` succeeds.
3. `:core:test --tests "com.ktome.core.combat.*"` succeeds.
4. `:game:test` succeeds.
5. `jacocoTestReport` generates aggregate and module reports under:
   - `build/reports/jacoco/test/html/index.html`
   - `core/build/reports/jacoco/test/html/index.html`
   - `game/build/reports/jacoco/test/html/index.html`
6. `:core:jacocoTestCoverageVerification` succeeds with:
   - `core` total line coverage `>= 70%`
   - `ecs / map / fov / turn / combat / pathfinding / ai` package line coverage `>= 85%`

## 2. Manual White-Box Verification

Launch the desktop client:

```bash
./gradlew :client:run
```

Controls:

1. `QWEASDZC` for 8-direction movement
2. Arrow keys for 4-direction movement
3. `Home`, `End`, `PageUp`, `PageDown` for diagonals
4. Numpad `1-9` for 8-direction movement
5. `S`, `.`, `Space`, or Numpad `5` to wait

Expected outcomes:

1. The window opens into the fixed-seed dungeon and shows the player `@` plus at least three monster archetypes.
2. Moving into an adjacent monster resolves combat instead of overlap.
3. Message log entries explain misses, hits, critical hits, deaths, experience gains, and level-ups.
4. `CHASE` monsters steadily close distance to the player.
5. `KITE` monsters try to keep distance and attack from their preferred range band.
6. `PATROL` monsters move along their patrol route until they detect the player, then switch to chase behavior.
7. Monster death removes the glyph from the map.
8. After enough kills, the player level increases and the status bar reflects updated XP / level / point totals.

## 3. Reproducibility Contract

1. The default session seed is `20260312`.
2. The default floor is `1`.
3. The default FOV radius is `8`.
4. Monster catalog comes from `game/src/main/resources/data/monsters.yaml`.
