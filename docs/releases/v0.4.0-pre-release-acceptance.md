# K-ToME v0.4.0 Pre-Release Acceptance

本文档定义 v0.4.0 桌面包随包交付口径，避免 0.4.x distribution 继续携带 v0.1.0 验收说明。

## Scope

v0.4.0 对应 Phase 4 V3 boss phase identity 与 version discipline 收口：

1. project version、桌面窗口标题、content pack range 与随包文档统一使用 0.4.x 口径。
2. `bossHarness` 的 phase/variant identity 指标必须进入 `reportPhase4` owner metric 面。
3. sample content pack 仍作为 0.4.x validation pack 随桌面包分发。

## Required Gates

发布候选包生成前必须真实执行并记录结果：

```bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk env
./gradlew verifyChanged
./gradlew phase4Report
./scripts/verify-bootstrap.sh
```

若本次只验证 release packaging，可额外执行：

```bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk env
./gradlew :client:distZip
```

## Artifact Checks

验收 `client/build/release/ktome-v0.4.0-desktop.zip` 时，至少确认：

1. 包内 `docs/` 不包含 `v0.1.0-pre-release-acceptance.md` 或 `v0.1.0-known-limitations.md`。
2. 包内包含 `v0.4.0-pre-release-acceptance.md` 与 `v0.4.0-known-limitations.md`。
3. 包内包含 `content-packs/sample.flooded_relics/manifest.yaml`。
4. 解压后桌面入口启动时窗口标题显示 0.4.x 版本口径。
5. `tools/build/reports/verification/phase4/report-phase4-summary.json` 的 owner metrics 包含：
   - `phaseTransitionObservedRatio`
   - `variantTraceDivergenceRatio`
   - `minVariantActionTraceDivergenceScore`
   - `bossVariantBasePhaseCountMin`

## Acceptance Boundary

本文件只定义 v0.4.0 pre-release packaging 与 owner report 验收口径，不替代 Phase 4 roadmap、verification checklist 或 PR 级设计文档。
