# K-ToME v0.4.0 Known Limitations

本文档记录 v0.4.0 桌面包随包限制，避免 release distribution 继续继承 v0.1.0 交付口径。

## Current Limits

1. 仍是单机单人短局/长局验证路径，不提供联机、账号、云存档或跨设备同步。
2. 旧存档兼容性不作为 v0.4.0 目标；不匹配的 save contract 应 fail fast。
3. Phase 4 content pack 支持仍停留在 manifest/schema/overlay 级扩展，不提供 Lua runtime、完整 Mod SDK 或运行时脚本宿主。
4. sample pack 是 validation pack，不代表最终内容量目标。
5. `bossHarness` owner metrics 只证明 boss phase identity 与 variant trace divergence 的当前合同满足，不替代 Phase 5 tactical AI/replay 稳定性验收。

## Verification Notes

v0.4.0 的 release readiness 以当前 Phase 4 checklist、`verifyChanged`、`phase4Report` 和 packaging gate 的真实结果为准。任何未执行的白盒或人工启动检查都必须在发布记录中明确标注为未覆盖项。
