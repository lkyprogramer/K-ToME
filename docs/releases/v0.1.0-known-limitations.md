# K-ToME v0.1.0 Known Limitations

This release intentionally stops at the Phase 1 MVP boundary.

## Gameplay

1. Only the desktop build is packaged.
2. The dungeon is fixed to a five-floor run with a single boss.
3. There is one player archetype and one four-slot warrior talent loadout.
4. Inspect mode explains only the live objects on the current floor; it is not a codex or history log.

## UX

1. The client remains ASCII-first and keyboard-first.
2. There is no mouse-driven inspect, inventory, or targeting flow.
3. Localization, remappable keybinds, and accessibility options are not implemented.

## Content and Systems

1. There is no mod runtime, network play, or multi-save-slot support.
2. Balance is tuned against a fixed seed sample, not a large telemetry corpus.
3. Visual effects, audio polish, and tile art are intentionally minimal in Phase 1.
