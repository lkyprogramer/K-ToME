# K-ToME v0.1.0 Pre-Release Acceptance

本文件定义当前桌面包在对外发布前必须完成的最小验收面。

当前文档已经同步到 `Phase 2 / P2-W3` 之后的真实门禁，重点覆盖：

1. `preReleaseAcceptance` 的真实 Gradle 依赖链
2. `localeLint / contractLint` 的正式回归入口
3. 主菜单 locale 选择、新开局、`Ctrl+S -> 返回菜单 -> Continue` 的双语白盒步骤

## 1. Direct Conclusion

发布前验收分成两层：

1. 自动化门禁：证明规则、schema/i18n、客户端生命周期、覆盖率和打包产物都过线。
2. 桌面白盒：证明真实桌面环境中的交互体验没有偏离自动化 smoke 的假设。

自动化通过，不等于可发布。桌面白盒没有执行，也不能把验收状态标成完成。

## 2. Automated Gate

仓库根目录执行：

```bash
./gradlew preReleaseAcceptance
```

该任务必须同时完成：

1. `clean`
2. `test`
3. `localeLint`
4. `contractLint`
5. `headlessSmoke`
6. `clientSmoke`
7. `jacocoTestReport`
8. `:core:jacocoTestCoverageVerification`
9. `:client:releaseDesktopDist`

自动化证据位置：

1. `build/reports/harness/headless-smoke.json`
2. `build/reports/harness/client-smoke.json`
3. `tools/build/reports/tests/localeLint/index.html`
4. `tools/build/reports/tests/contractLint/index.html`
5. `build/reports/jacoco/jacocoTestReport/html/index.html`
6. `core/build/reports/jacoco/test/html/index.html`
7. `client/build/release/ktome-v0.1.0-desktop.zip`

如果只做局部自证，至少应能单独执行：

```bash
./gradlew :game:test
./gradlew localeLint
./gradlew contractLint
./gradlew headlessSmoke
./gradlew clientSmoke
./gradlew preReleaseAcceptance
./gradlew test
```

Nightly 扩展验证：

```bash
./gradlew longRunLab
```

Nightly 证据位置：

1. `build/reports/harness/long-run-summary.json`
2. `build/reports/harness/long-run-summary.md`

## 3. Desktop White-Box Gate

桌面环境中执行：

```bash
./gradlew :client:run
```

必须人工确认：

1. 主菜单可以进入 `New Game` 和 `Continue`，并能看到当前语言标签。
2. 在主菜单切到 `zh-CN`，确认主菜单标题、语言标签都切成中文。
3. 用中文开新局，确认菜单、HUD、首条日志、背包标题、检视标题都按中文渲染。
4. 执行一次 `Ctrl+S -> 返回菜单 -> Continue`，并在 Continue 前切回 `en-US`。
5. 继续读档后，确认楼层、HUD、日志、背包、检视都按当前英文 locale 重渲染，而不是沿用存档里的旧字符串。
6. `x` 检视模式能解释玩家、怪物、地面物品，且楼梯名称按当前 locale 显示。
7. `>` / `<` 上下楼流程与自动化 smoke 一致。
8. 至少完成一条 Victory 路径和一条 Death 路径。
9. 对照 `build/reports/harness/client-smoke.json`，确认 locale 场景与桌面白盒结论一致。
10. 解压 `client/build/release/ktome-v0.1.0-desktop.zip` 后，独立启动一次。

## 5. Known Boundaries

当前验收仍然遵守以下边界：

1. 仅桌面版打包。
2. 当前正式内容基线已切到 `Schema V2 + locale`，并以 formal `zone/profession` id 驱动会话。
3. 当前短局以 `ZoneSpec` 为真源；首批 `Phase 2` zone 基线是 `2` 层短局，不再以单一 `5` 层默认 run 作为权威口径。
4. 主菜单 locale 选择必须同时影响 `New Game` 和 `Continue`。
5. 自动化 smoke 是发布前证据的一部分，不替代真实桌面白盒。
