# Phase 2 Roadmap（入口）

## 1. Phase 2 主题

Phase 2 的主题不是继续堆内容，而是先把 Phase 1 的最小可玩主线迁移到可长期演进的语义合同上，再建立最小 Tile、最小双语言、最小资源管线闭环。

目标主线：

`Phase 1 可玩 MVP -> 语义合同重建 -> Tile/i18n 正式路径 -> 4 职业短局`
