# PR-08 V32 Bottom Log Ledger Density

## Verdict

Accepted-forward only.

V32 switches from V31 right-panel equipment density to the bottom log deck. The
bottom log now draws each visible event on a subdued row plate with a tone-aware
accent strip, so the deck reads more like a dense event ledger and less like one
flat paragraph block.

This is not director-grade closure. The row structure improves scanability, but
the reference still has stronger bottom-deck icon subjects, richer action-slot
material and more authored log hierarchy.

## Scope

- Production:
  - `client/src/main/kotlin/com/ktome/client/render/DemoShellRenderer.kt`
- Tests:
  - `client/src/test/kotlin/com/ktome/client/render/TileRendererCanvasTest.kt`
- Evidence:
  - `UI/review/dark-uiux-pr08-exploration/runtime-bottom-log-ledger-density-v32/`

No gameplay rules, core visibility, save, replay, profile, schema, manifest
schema, content-pack rule, resource file, owner-contract or golden expected-hash
change.

## Implementation

1. Reused the existing `visibleLines` computed by `renderLogAndStats`.
2. Added `drawLogEventRowPlates` inside the existing DemoShell render path.
3. Drew one low-alpha row plate per visible log row before text rendering.
4. Added one tone-aware side accent strip per row using the existing
   `logLedgerAccentHex` tone mapping.
5. Kept log text, wrapping, icons and event source data unchanged.

The pass is presentation-only and remains in `client`; it does not introduce a
second log model, second tone authority or temporary compatibility path.

## Manual Review

V32 is accepted-forward because the bottom log now has visible event-row
structure and tone markers without changing event data or sacrificing text
readability.

Remaining director blockers:

1. action slots still need stronger readable icon subjects and material detail
2. the log deck still lacks the reference-quality authored hierarchy
3. right-side gear still depends on placeholder-like runtime glyphs
4. map-stage director blockers from V31 remain unchanged

## Next Action

Do not continue by only increasing row-plate alpha. The next useful pass should
target bottom action-slot icon/detail richness, authored equipment placeholders
or a larger map-stage composition/resource move.
