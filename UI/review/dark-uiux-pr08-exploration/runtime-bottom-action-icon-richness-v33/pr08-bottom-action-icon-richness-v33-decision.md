# PR-08 V33 Bottom Action Icon Richness

## Verdict

Accepted-forward only.

V33 follows the V32 bottom-log pass and targets the bottom action slots. The
runtime now renders larger action icon subjects and adds warm material underlines
plus restrained side glints inside filled action sockets, so the hotbar reads
less like small symbols placed in generic buttons.

This is not director-grade closure. The action icons are clearer than V32, but
the pass still uses the existing circular combat-icon resources. The reference
bottom deck has stronger authored sword/shield/compass subjects and a cleaner
rectangular slot silhouette.

## Scope

- Production:
  - `client/src/main/kotlin/com/ktome/client/render/DemoShellRenderer.kt`
- Tests:
  - `client/src/test/kotlin/com/ktome/client/render/TileRendererCanvasTest.kt`
- Evidence:
  - `UI/review/dark-uiux-pr08-exploration/runtime-bottom-action-icon-richness-v33/`

No gameplay rules, core visibility, save, replay, profile, schema, manifest
schema, content-pack rule, resource file, owner-contract or golden expected-hash
change.

## Implementation

1. Reused `ActionPanelEntryModel.icon` as the only action-icon authority.
2. Increased the drawn action icon subject from a `0.17` socket inset to `0.12`.
3. Added `drawActionIconSubjectAccents` inside the existing action deck renderer.
4. Drew low-alpha subject backing, brass underline, brass side glint, cyan side
   rim and a small top material line for filled action sockets only.
5. Kept labels, hotkeys, action ordering and action availability unchanged.

The pass is presentation-only and remains in `client`; it does not derive action
meaning from labels or row index, and it does not introduce a second action
model or replacement icon registry.

## Manual Review

V33 is accepted-forward because action icons have more first-glance weight and
the slot centers gain material cues without changing command semantics.

Remaining director blockers:

1. action icons remain the existing circular combat-resource set
2. reference-quality sword, shield and compass subjects likely require authored
   resource replacement or action-specific icon mapping
3. rectangular slot silhouette and bottom deck proportions still diverge from
   the reference
4. map-stage director blockers from V32 remain unchanged

## Next Action

Do not continue by only making the current icon scale larger. The next useful
pass should be a resource-level action icon / slot silhouette iteration, or a
larger map-stage composition move if first-screen map quality becomes the
dominant blocker again.
