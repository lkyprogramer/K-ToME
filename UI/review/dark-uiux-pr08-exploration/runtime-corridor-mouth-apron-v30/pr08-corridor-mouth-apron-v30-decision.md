# PR-08 V30 Runtime Corridor Mouth Apron

## Verdict

Accepted-forward only.

V30 moves from V29's room-scale material resource into corridor-mouth
architecture. It strengthens the existing passage-threshold compositor so wide
room-side corridor openings get a carved stone apron, a restrained worn sill
and asymmetric abutments on both vertical and horizontal entrances.

This is not director-grade closure. The corridor mouths integrate better with
the room floor/wall mass, but the full map still reads more grid-forward and
less organically staged than `UI/UI-demo-new.png`. The measured map delta is
real but small, so the next pass should not keep tuning this same local
corridor apron.

## Scope

- Production:
  - `client/src/main/kotlin/com/ktome/client/render/TileRenderer.kt`
- Tests:
  - `client/src/test/kotlin/com/ktome/client/render/TileRendererCanvasTest.kt`
- Evidence:
  - `UI/review/dark-uiux-pr08-exploration/runtime-corridor-mouth-apron-v30/`

No gameplay rules, map generation, core visibility, save, replay, profile,
schema, manifest schema, content-pack rule, resource file, owner-contract or
golden expected-hash change.

## Implementation

`drawVisiblePassageThresholds(...)` now adds room-side apron pieces only when
the existing wide-mouth checks already prove the corridor tile opens into a
wide room side:

1. a darker room-side stone apron just inside the room
2. a smaller warm worn-stone sill on top of that apron
3. asymmetric side abutments tying the threshold into the room wall/floor
   junction
4. four-direction coverage for north, south, east and west room entrances

The pass is presentation-only and remains inside `MAP_ROOM_COMPOSITOR`. It
does not create a second visibility, map, save, replay or content-pack
authority.

## Manual Review

V30 is accepted-forward because corridor entrances now have a readable
room-side masonry threshold instead of stopping at the one-tile throat cap. The
change is isolated to the map surface: right panel, bottom deck, nav and
inventory crops remain unchanged.

Remaining director blockers:

1. the map-stage delta is still modest versus V29
2. the room still reads more grid-first than the reference crop
3. right panel and bottom deck density remain below the target's first-read
   richness
4. another local corridor apron opacity or rectangle pass would likely have
   diminishing return

## Next Action

Do not continue tuning the same corridor-mouth apron. Move to one of these
technique changes:

1. a right-panel/bottom-deck density and chrome slice, or
2. a stronger map-stage composition pass that changes room placement/black-field
   balance rather than local doorway opacity, or
3. a generated/authored resource-backed corridor/wall-thickness family if the
   next map pass remains resource-owned.
